# autor.krick.me

## Überblick

Statische Astro-One-Page für den Dark-Romance-Roman "Lara 47 - Zwischen Kontrolle und Hingabe" von Attila Krick. Die Seite stellt Buch, Autor, Musik und Trailer vor und führt zur Amazon-Produktseite. Sie läuft ohne Cookies, Tracking oder automatisch geladene Inhalte von Drittanbietern. Das Produktionsziel ist Cloudflare Workers Static Assets unter `https://autor.krick.me`.

## Voraussetzungen

- Node.js 24 oder neuer
- npm 11 oder neuer
- Cloudflare-Zugriff für Deployments

## Entwicklung

```sh
npm install
npm run dev
```

## Prüfung

```sh
npm run check
npm run build
```

## Deployment

```sh
npm run deploy
```
